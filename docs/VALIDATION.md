# 重构实施与验证

日期：2026-09-25。功能参考：`legacy/original-v1.3.html`，保留远端 `archive/` 和原许可证。

## 方案进度

- Phase 0：React/TS 前端、画册式布局、勿忘我蓝、精简文案、键盘操作、关于页仓库链接。
- Phase 1：真实 Caption API、无硬性并发上限、可取消队列、每 Worker 独立 ONNX 会话、Transferable、WebGPU/WASM 回退与独立 Worker 并行。
- Phase 2：预设与本地模型、旧 IndexedDB 缓存复用、CSV 解析、阈值/触发词/转义、ZIP 及确认后写回文件夹。
- Phase 3：测量式虚拟瀑布流、512px 缩略图、设置持久化及旧 API 配置迁移、中英切换、PWA/离线资源、字体本地打包。
- Phase 4：API/本地推理重试、下载流式进度与持久化断点续传，服务器不支持续传时完整重下。

可选的 `coi-serviceworker` 未启用。实际并行依靠多 Worker，每个 WASM 会话保持 `numThreads = 1`，没有加入跨域隔离头或改变 API 的跨域策略。PWA Service Worker 只缓存本站应用资源，不拦截或缓存第三方 API 请求。

## 验证边界

测试 ONNX 是仓库内可重建的极小通道均值模型，不是训练过的 WD 模型。本轮没有下载数百 MB 的各个预设权重，因此没有宣称达到方案中估计的 4–7 倍速度，也没有完成新旧版本在真实 WD 权重上的逐标签基准。

Caption API 使用自动测试和本地兼容端点验证，未使用用户凭据调用收费端点。文件夹写回已通过模拟 File System Access 句柄验证授权、冲突和写入完成状态；不同浏览器的原生目录授权对话框仍由用户操作。

断点续传依赖服务器正确支持 Range，并通过 CORS 暴露所需校验/范围头。无这些头时不拼接无法验证的字节。
